# Суши ORDO — Cafe Menu Board (Версия 2)

Живое цифровое меню для **6 телевизоров** с панелью администратора и синхронизацией данных через облако GitHub Pages.

---

## ⚙ Админка

Панель управления меню:
[`https://ahror1994.github.io/cafe-menu-board-v2/#/admin`](https://ahror1994.github.io/cafe-menu-board-v2/#/admin)

- **Интерактивный холст:** перетаскивайте плашки с блюдами и ценами мышкой.
- **Мгновенное сохранение:** изменения отправляются в облако репозитория.
- **Автоматическое обновление ТВ:** телевизоры подтягивают свежие данные по сети.

---

## 🚀 Локальная разработка и деплой

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build

# Деплой в GitHub Pages (ветка gh-pages)
npm run deploy
```
